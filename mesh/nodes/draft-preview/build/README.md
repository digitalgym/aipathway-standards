# Draft Preview

Before a bot writes an invoice, bill, credit note, spend or receive money or
manual journal into a client's Xero file, Draft Preview works every figure out
again from the draft's own lines. It reads the ledger's tax rates first, works
out the GST on each line, adds up the totals and lists the journal the document
will post. A draft a cent out, a tax type the ledger does not hold, or a journal
that does not balance is parked for the bookkeeper with both sets of figures.

Nothing is written until a named person releases the preview. Then the document
is written once, with the key `preview:<tenant>:<draft>:<preview>`, and read
back so the totals Xero stored can be compared to the cent. A dry run previews
and parks as usual and writes nothing.

Built to AIP-BS-LEDGER-WRITE-PREVIEW. In production the preview comes from
preview_draft on the AI Pathway connector (connect.aipathway.com.au).

    node run.mjs       the conformance run
    node mutants.mjs   proof every scenario goes red for a do-nothing build and a broken one

Generated by `npx @aipathway/conformance init ledger-write-preview-build-standard`.

## The second run

There is no second run for this standard yet. Its live port map is not
published, so this folder has no `ports.mjs`, and `AIPATHWAY_ENV=production`
is refused rather than rerunning the stub under a production label. The stub run
is the whole of what can be proved here.

AI Pathway's preview_draft, on the AI Pathway connector at connect.aipathway.com.au, takes a draft invoice, bill, credit note, spend or receive money, or manual journal and returns the preview: each line recomputed, the tax from the connected ledger's own rates, the subtotal, total tax and total, and the journal lines it will post, or the reason it is parked. Call it on the AI Pathway MCP (office_voice.preview_draft): the owner mints a key at connect.aipathway.com.au/app/keys with the scope the tool names, on any AI Pathway account. There is no production run of these checks yet, so the stub run is the finished build; AIPATHWAY_PROVIDER=office_voice.preview_draft needs a live port map that is not published. Do not hand-roll the write.

The checks that never go green on the stub report `with_us`.
