# Open Home Desk: conformance harness

Open Home Desk is a port of "Mary (Realtor Assistant)" by Rick (https://x.ai/bot/eQ4tLI6SMBanz6rovfhyV), reimplemented from AIP-BS-OPEN-HOME-FEEDBACK 2026-10-24. Only the showing follow-up job is ported, and nothing is taken from the original bot's prompt or instructions. The build is `build.mjs`; the scenarios are `scenarios.mjs`.

Generated by `npx @aipathway/conformance init open-home-feedback-build-standard`.

    npm install
    node run.mjs

Every check starts red. That is the point: going green is the work, and a green
run means something because a red one was possible.

## The three files

| file | whose | what |
|---|---|---|
| `build.mjs` | yours | the build. The only file that does the job |
| `scenarios.mjs` | yours | one `holds` per check. Generated with the check's own words |
| `run.mjs` | ours | fetches the checks, runs, prints. No edits needed |

## This standard

14 checks: 12 provable here on the stub, 1 only in
production, 3 partial, 1 preconditions needing evidence rather than code.

The checks are fetched at run time from https://aipathway.com.au/explore-ai/open-home-feedback-build-standard,
so a correction published there reaches you without a release here.

## The second run

There is no second run for this standard yet. Its live port map is not
published, so this folder has no `ports.mjs`, and `AIPATHWAY_ENV=production`
is refused rather than rerunning the stub under a production label. The stub run
is the whole of what can be proved here.

The optional call is Office Voice's governed single call: create_call, basis they_asked, only to an attendee who asked to be called, and off unless the agent turns it on. The consent and unsubscribe record at volume, and a record of who said what that survives a vendor dispute, are not a product and are quoted as a scoped build. Queue each call with create_call on the Office Voice MCP (office_voice.create_call): the owner mints the key at office-voice.com/app/keys and ticks "Allow this to queue calls", and the dispatcher does the Do Not Call Register check, the calling hours and the one-attempt-a-day limit. There is no production run of these checks yet, so the stub run is the finished build. Do not stand up telephony of your own.

The checks that never go green on the stub report `with_us`.
