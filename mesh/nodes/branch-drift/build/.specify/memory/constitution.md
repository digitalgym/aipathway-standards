# Constitution

Loaded before any work. These are not conservative defaults: they are the
points where an Australian business carries an obligation a machine cannot hold.

## Never

- treat training material as a control
- compute the score twice
- invent a key

## Stays with a person

- accepting a local variation as legitimate, and recording why
- changing the key contract, which is a version bump and not an edit
- every conversation with a segment that has crossed a threshold
- judging whether a low score is a compliance problem
- deciding a new segment is ready to take real records

## Always

- Every port call is awaited and goes through the ports handed to the build.
- Assert on the recorded trace, never on stub memory.
- Do not mark the build finished; the pass test does that.
- If the standard's edition moves, rebuild from it.
