## This node: Notice Check

The rent arrears standard, built around the statutory clock. A breach notice
for rent is drafted only when a fresh ledger read and the dated rule for the
tenancy's state (QLD, NSW, VIC) say it is due. The exception that holds it
carries the paid-to date, the rule version, the day the threshold was met and
the earliest remedy date. When a named person releases it, the notice is
checked again against the ledger and the rule in force that day, so a tenant
who paid in between is never served. Serving, and the service method, stay
with that person. `scenarios.mjs` check 6 stages all of it.
