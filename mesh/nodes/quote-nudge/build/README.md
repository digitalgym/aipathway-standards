# Quote Nudge: follow-up-build-standard conformance harness

Quote Nudge chases one kind of open item, `quote_decision`: a flooring quote
the rep sent that nobody has answered. Texts and emails are low-pressure
drafts the rep releases, counted as a touch when drafted. A call, where the
business's cadence has one, is the hosted step (Get Paid on Office Voice);
`build.mjs` only proves its shape on the stub. See the header of `build.mjs`.

Before the committed run, the scenarios were run against a do-nothing build
(every runnable check red) and against broken builds made by wrapping the
ports: a gate that always allows, consent ignored, value hidden so it sorts
by age, arrivals hidden, the ask before the disclosure, free-text outcomes, no
escalation, no notification, every kind chased, we_owe ignored, and a record
read with no history. Each claimed check went red for at least one of them.

Generated by `npx @aipathway/conformance init follow-up-build-standard`.

    npm install
    node run.mjs

Every check starts red. That is the point: going green is the work, and a green
run means something because a red one was possible.

## The three files

| file | whose | what |
|---|---|---|
| `build.mjs` | yours | the build. The only file that does the job |
| `scenarios.mjs` | yours | one `holds` per check. Generated with the check's own words |
| `run.mjs` | ours | fetches the checks, runs, prints. No edits needed |

## This standard

13 checks: 11 provable here on the stub, 1 only in
production, 1 partial, 1 preconditions needing evidence rather than code.

The checks are fetched at run time from https://aipathway.com.au/explore-ai/follow-up-build-standard,
so a correction published there reaches you without a release here.

## The second run

There is no second run for this standard yet. Its live port map is not
published, so this folder has no `ports.mjs`, and `AIPATHWAY_ENV=production`
is refused rather than rerunning the stub under a production label. The stub run
is the whole of what can be proved here.

Enable Get Paid on Office Voice / Recover; npx @aipathway/conformance connect gets the owner a key and the links to connect their systems. There is no production run of these checks yet: AIPATHWAY_PROVIDER=office_voice.recover needs a live port map that is not published, so the stub run is the finished build. Do not hand-roll the live step.

The checks that never go green on the stub report `with_us`.
