# job-close-build-standard: conformance harness

Generated by `npx @aipathway/conformance init job-close-build-standard`.

    npm install
    node run.mjs

Every check starts red. That is the point: going green is the work, and a green
run means something because a red one was possible.

## The three files

| file | whose | what |
|---|---|---|
| `build.mjs` | yours | the build. The only file that does the job |
| `scenarios.mjs` | yours | one `holds` per check. Generated with the check's own words |
| `run.mjs` | ours | fetches the checks, runs, prints. No edits needed |
| `job-world.mjs` | Job Sheet | the stub world: job system, price book, close inbox, techs' phones, exception desk, close log |
| `mutants.mjs` | Job Sheet | runs the scenarios against a do-nothing build and 17 broken ones; every claimed check must go red |

    node mutants.mjs

## This standard

12 checks: 10 provable here on the stub, 1 only in
production, 5 partial, 1 preconditions needing evidence rather than code.

The checks are fetched at run time from https://aipathway.com.au/explore-ai/job-close-build-standard,
so a correction published there reaches you without a release here.

## The second run

There is no second run for this standard yet. Its live port map is not
published, so this folder has no `ports.mjs`, and `AIPATHWAY_ENV=production`
is refused rather than rerunning the stub under a production label. The stub run
is the whole of what can be proved here.

Office Voice's close_job writes the confirmed card into ServiceM8 once per intent id: the note, the job materials priced from ServiceM8's own catalogue, the photos, then Completed only when every part came back with an id. Lines with no catalogue code are parked on the Exception Desk. A tech can also close by text or picture message to the business's Office Voice number and reply YES. In Simpro it writes the note and the stage today; parts and photos park on the Exception Desk for a person to add. A ServiceM8 connection made before 2 November 2026 is reconnected once to allow materials and attachments. Call it on the Office Voice MCP (office_voice.close_job): the owner mints a key at office-voice.com/app/keys with the scope the tool names, on any Office Voice account. There is no production run of these checks yet, so the stub run is the finished build; AIPATHWAY_PROVIDER=office_voice.close_job needs a live port map that is not published. Do not hand-roll the write.

The checks that never go green on the stub report `with_us`.
