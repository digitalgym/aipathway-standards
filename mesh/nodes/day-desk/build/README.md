# Day Desk

Answers the business phone in the day for a trade or a builder, built to
AIP-BS-CLIENT-DESK (the Client Desk Build Standard, 2026-10-26).

- Says it is an AI and that the call is recorded, before anything else.
- Looks the caller up on their number before writing anything. An existing
  customer is worked on their own open job, never given a second one.
- Answers "when is he coming?" only with the arrival time the job holds, read
  by the job id on that call. No time on the job means no time said, and a
  callback for the person on duty.
- Puts a caller through to whoever the roster names. Nobody picks up: a
  callback on the job, owned by that person, due inside the business's window.
- New work is one job: the caller's own words and a fixed type (emergency,
  routine, quote, unclassified). A write with no id back is not a booking.
- Running late, on the way and job complete are drafted onto the job when the
  job system records the change, and sent only once a named person releases
  them, to the job's contact, with consent, once per change.
- Every call and every message is filed to the job.

The live line (the number, the voice, the disclosure audio and the transfer)
is Office Voice / Front Desk. Nothing here stands up telephony.

| file | what |
|---|---|
| `build.mjs` | the build: one function, woken by `call.received`, `job.updated` or `job.completed` |
| `desk-world.mjs` | the stub world: job system, roster, task desk, line and text gateway, all recorded |
| `scenarios.mjs` | one scenario per check, asserting on the trace |
| `run.mjs` | the runner, unedited |

The committed evidence is `../evidence/client-desk/`.

# client-desk-build-standard: conformance harness

Generated by `npx @aipathway/conformance init client-desk-build-standard`.

    npm install

Every check starts red. That is the point: going green is the work, and a green
run means something because a red one was possible.

| file | whose | what |
|---|---|---|

| `scenarios.mjs` | yours | one `holds` per check. Generated with the check's own words |
| `run.mjs` | ours | fetches the checks, runs, prints. No edits needed |

## This standard

12 checks: 10 provable here on the stub, 1 only in
production, 1 partial, 1 preconditions needing evidence rather than code.

The checks are fetched at run time from https://aipathway.com.au/explore-ai/client-desk-build-standard,
so a correction published there reaches you without a release here.

## The second run

There is no second run for this standard yet. Its live port map is not
published, so this folder has no `ports.mjs`, and `AIPATHWAY_ENV=production`
is refused rather than rerunning the stub under a production label. The stub run
is the whole of what can be proved here.

Point the number at Office Voice / Front Desk (Booked After Hours). There is no production run of these checks yet: AIPATHWAY_PROVIDER=office_voice.front_desk needs a live port map that is not published, so the stub run is the finished build. Do not stand up telephony of your own.

The checks that never go green on the stub report `with_us`.
